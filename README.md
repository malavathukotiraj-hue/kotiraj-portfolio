# Kotiraj Portfolio

A responsive personal portfolio website for Kotiraj, a diploma student interested in web development, artificial intelligence, and cybersecurity.

## Features

- Responsive portfolio layout for desktop and mobile screens
- Smooth navigation between Home, About, Skills, Projects, Education, and Contact sections
- Animated role text powered by JavaScript
- Skills showcase for HTML, CSS, JavaScript, Python, AI/ML, and Cybersecurity
- Featured project section
- Profile image and social links for GitHub and LinkedIn
- Contact email link
- GitHub Pages deployment workflow

## Built With

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/malavathukotiraj-hue/kotiraj-portfolio.git
   cd kotiraj-portfolio
   ```

2. Start a local server. For example, with Python:

   ```bash
   python -m http.server 8000
   ```

3. Open `http://localhost:8000` in a browser.

## Deployment

The site is deployed automatically with GitHub Pages whenever changes are pushed to the `main` branch. The deployment workflow is located at `.github/workflows/pages.yml`.

this site is live at: https://malavathukotiraj-hue.github.io/kotiraj-portfolio/
